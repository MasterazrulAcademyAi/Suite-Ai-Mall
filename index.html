PENGURUSAN DATA KELAS

Sync Jadual Kelas ke Telefon & GitHub

Mengapa kelas tak muncul bila buka di telefon?
GitHub Pages ialah hosting statik. Apabila anda simpan kelas di PC, ia tersimpan di memori PC anda. Agar telefon dan orang luar di seluruh dunia dapat melihat kelas baru ini, pilih salah satu kaedah di bawah:
1

Kaedah 1: Muat Turun & Drag ke GitHub (100% Berjaya & Percuma)

DISYORKAN

Muat turun fail classes-data.js terkini daripada komputer ini, kemudian masukkan ke repository GitHub anda:

Buka Repo GitHub Anda →
3 Langkah Mudah: Buka repo GitHub di atas → Tarik fail classes-data.js ke dalam laman GitHub → Klik butang hijau 'Commit changes'. Dalam 30 saat, telefon anda akan terus memaparkan kelas ini!
2

Kaedah 2: Auto-Sync 1-Klik via GitHub Token (Tanpa Perlu Upload)

PANTAS

Masukkan GitHub Personal Access Token (PAT) anda sekali sahaja. Anda hanya perlu tekan butang 'Sync Sekarang' setiap kali tambah kelas baru!

* Dapatkan token di: GitHub Settings → Developer Settings → Personal access tokens (Tandakan skop: repo). Token disimpan selamat di browser PC anda.

3

Kaedah 3: Salin Pautan Kongsi Lengkap (Untuk WhatsApp / Bio)

SEGERA

Pautan khas ini mengandungi semua data kelas yang anda simpan di PC. Bila anda buka link ini di telefon atau beri pada prospek di WhatsApp, telefon akan automatik sync dan memaparkan semua kelas tersebut!
